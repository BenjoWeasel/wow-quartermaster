# WoW Quartermaster

**WoW Quartermaster** is a personal, noncommercial companion project for **World of Warcraft: Forever**. It combines character information collected by a lightweight in-game addon with an external advisor to support practical gameplay decisions.

## What it does

The addon captures information about the player's own character, such as equipment, talents, abilities, quests, and progression. This character snapshot can be reviewed by an external advisor for:

- Planning dungeon runs alongside relevant quest chains and prerequisites
- Identifying useful dungeon quests before entering an instance
- Comparing equipment and character progression
- Preparing for later dungeon and raid content

The advisor is intended to provide recommendations **outside the game**, not automate gameplay.

## Game reference data

The project is exploring read-only game reference sources to supplement the character snapshot with information about quests, quest chains, dungeon encounters, items, and spells. Any ForeverDB API integration is **planned, not yet active**, and would be used on demand at low volume for personal gameplay planning.

**ForeverDB attribution:** [ForeverDB.net](https://foreverdb.net/) is a community game reference resource being evaluated for this project. If ForeverDB data is used or displayed, it will be visibly credited and linked to its source.

## Project status

This repository is a public description of a personal project and its intended data use, including for reference-data access applications. It is **not** a distribution of the in-game addon or its development source.

No API keys, account information, character exports, or private configuration files are published here.
